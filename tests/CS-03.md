# Success criteria for CS-03 (Streak calculation)

Each case must hold for an implementation to satisfy CS-03.
"Today" is 2026-11-24 in the client's local time zone.

| Case | Check-in dates (local) | Expected streak | Why |
|---|---|---|---|
| CS-03-a | 11-22, 11-23, 11-24 | 3 | Consecutive days ending today |
| CS-03-b | 11-21, 11-22, 11-23 | 3 | Ending yesterday still counts |
| CS-03-c | 11-20, 11-21, 11-22 | 0 | Neither today nor yesterday |
| CS-03-d | 11-24, 11-24, 11-23 | 2 | Duplicates on one day count once (see CS-02) |
| CS-03-e | 11-24 at 11:30 PM in Miami | 1, dated 11-24 | Local time zone, not UTC (UTC would say 11-25) |
| CS-03-f | none | 0 | Empty history |
